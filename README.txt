PAKEJ GITHUB PAGES - Portal Shariah Compliance PUSRAWI

Cara muat naik:
1. Buat repository baharu di github.com (contoh: portal-syariah).
2. Muat naik SEMUA fail & folder dalam pakej ini ke root repository
   (index.html mesti berada di paras atas, bukan dalam subfolder).
3. Pergi ke Settings > Pages > Source: pilih "Deploy from a branch",
   branch "main", folder "/ (root)", tekan Save.
4. Tunggu 1-2 minit; portal akan tersedia di:
   https://NAMAANDA.github.io/portal-syariah/

Nota: Jangan tukar nama mana-mana fail - semua pautan bergantung padanya.
